# putisj-community
AI Adventure Themes &amp; Creative Packs


一个面向 **putisj** 的公开创意分享仓库。

这里用于分享大家制作的 JSON 配置包，让其他人可以浏览、参考、导入和二次创作。

不需要复杂分类，也不需要注册其他网站账号。只要提交一个符合要求的 JSON 文件，就可以分享你的作品。

## 📦 分享什么？

欢迎分享各种 putisj 相关创意，例如：

- UI 主题、配色、界面配置和 CSS
- 世界观、剧本、剧情和故事设定
- NPC、角色设定和人物关系
- 任务、事件和游戏内容
- 插件、扩展及其他创意配置

以上内容统一以 JSON 文件分享，不需要按照内容类型建立文件夹。

## 📝 如何投稿？

通过 GitHub 投稿：

1. 登录 GitHub，进入本仓库。
2. 点击右上角的 **Fork**，复制一份仓库到自己的账号。
3. 进入你 Fork 的仓库，点击 **Add file → Upload files**。
4. 上传你的 JSON 文件。
5. 填写简短的提交说明，然后点击 **Commit changes**。
6. 回到本仓库，点击 **Contribute → Open pull request**。
7. 在投稿说明中简单介绍作品，并注明是否原创、是否使用第三方素材。
8. 点击 **Create pull request**，等待维护者查看。

投稿文件建议使用容易理解的名称，例如：

- `my-theme.json`
- `forest-story.json`
- `new-npc.json`

每份作品尽量使用一个独立的 JSON 文件。

## ⚠️ 投稿注意事项

投稿前请确认：

- 你拥有投稿内容的版权，或已经获得合法授权。
- JSON 格式正确，能够正常读取。
- 不包含密码、API Key、访问令牌或个人隐私。
- 不包含未经授权的游戏资源、图片、字体、音乐、文本或代码。
- 如果使用了第三方素材，请注明来源和原始许可证。
- 如果内容包含 CSS、插件、扩展或可执行代码，请说明其用途和风险。

请不要上传恶意代码、窃取数据的程序、破坏性脚本或其他危险内容。

## 🔒 内容审核与安全

本仓库是一个轻量的兴趣分享项目，不保证随时有人维护或审核。

- 投稿不代表一定会被接受。
- 维护者可以拒绝、关闭或移除有问题的投稿。
- 发现侵权、危险代码或隐私泄露内容，可以通过 GitHub Issues 反馈。
- 不要随意运行或导入不熟悉的插件、扩展和代码。
- 即使投稿通过审核，也不代表内容绝对安全或不存在法律风险。

## ❤️ 最后

这里不追求复杂的规则，也不要求作品有多么完善。

无论是一个简单的 UI 配色、一套 NPC 设定，还是完整的故事配置，只要是合法、原创或获得授权的创意，都欢迎分享。
